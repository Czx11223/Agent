# 问诊对话语料库规范

- 版本：V1.0.0
- 服务对象：预问诊多轮对话 Agent（追问策略训练与评测）
- 配套文件：《04_语料清洗脚本.md》中的 `clean_inquiry_corpus.py`
- 安全声明：本语料库仅保留结构化问诊要素文本，**禁止包含真实患者身份与隐私**；发布/演示一律使用模拟样例。

---

## 1. 语料库定位与样本结构

语料库用于训练与评测"预问诊"多轮对话，每个基础样本为一条**三元组**：

```
【患者主诉】 → 【医生追问】 → 【患者补充回答】
```

- **患者主诉（chief_complaint）**：患者首次陈述的核心不适（症状 + 部位 + 时间等）。
- **医生追问（doc_followup）**：医生围绕症状要素发起的**澄清性追问**（部位/时间/伴随/既往），**不含诊断与用药**。
- **患者补充回答（patient_answer）**：患者对该追问的补充信息。

一个咨询案例可拆出多条"主诉+追问+补充"三元组，供模型学习"信息不足→继续追问"的行为，以及槽位抽取。

---

## 2. 输出字段规范

标准化 CSV / 语料 JSON 的统一字段（与清洗脚本输出一致）：

| 字段名 | 是否必填 | 类型 | 说明 | 约束 |
| --- | --- | --- | --- | --- |
| `id` | 是 | TEXT | 样本唯一编号 | 格式 `S000001` |
| `chief_complaint` | 是 | TEXT | 患者主诉 | 非空；≥5 字符；去隐私 |
| `doc_followup` | 是 | TEXT | 医生追问 | 非空；疑问句式；非诊断/无用药 |
| `patient_answer` | 是 | TEXT | 患者补充回答 | 非空；与追问语义相关 |
| `department` | 否 | TEXT | 科室 | 可为空 |
| `symptom` | 否 | TEXT | 症状要素摘要 | 可为空 |
| `source_file` | 是 | TEXT | 来源文件 | 用于溯源 |
| `quality_score` | 是 | FLOAT | 质量分 0~1 | 保留阈值 ≥ 0.6 |

**槽位对齐（用于训练覆盖）**：每条主诉应能抽取到以下五类追问要素中的至少一类——`主要症状 / 部位 / 持续时间 / 伴随症状 / 既往史(含过敏史)`。

---

## 3. 黑名单（禁止样本）

> 核心原则（对齐任务书合规要求）：**预问诊只做症状信息收集，不做诊断、不开药**。以下内容命中即剔除。

### 3.1 诊断类（A 类，剔除轮次/样本）

| 模式示例 | 说明 |
| --- | --- |
| 诊断为/确诊为/初步诊断为……（症/炎/癌/瘤/病/综合征） | 明确诊断结论 |
| 大概率是/很可能是……（病/症/炎） | 疑似诊断倾向 |
| 临床诊断符合……标准 | 诊断标准判定 |
| 属于……（细菌性咽炎 等） | 归因诊断 |

### 3.2 处方与用药类（B 类，剔除）

| 模式示例 | 说明 |
| --- | --- |
| 建议/可/应该服用 xx mg / xx 片 / 每日 xx 次 | 用药与剂量 |
| 口服/外用/肌注/静脉滴注 …… | 给药方式 |
| 处方/开药/用药建议/剂量/疗程…… | 处方内容 |
| 手术/化疗/放疗/住院治疗方案 | 治疗方案 |

### 3.3 诊疗动作 / 检查医嘱类（C 类，剔除）

| 模式示例 | 说明 |
| --- | --- |
| 建议做血常规/CT/胃镜/心电图…… | 检查执行指令（超出预问诊） |
| 建议马上去急诊/药店买…… | 处置引导（急重症除外，见 §5） |

### 3.4 隐私与脏数据（D 类，整条删除）

- 身份证号 / 手机号 / 银行卡号 / QQ / 微信号 / 家庭住址 / 明文联系方式。
- URL、超长数字串、乱码（中文占比 < 50%）、纯 emoji/符号文本。
- 结果文本为空、过短（<8 字符）。

---

## 4. 样本质量判定标准

质量分 `Q = 长度分×0.5 + 中文占比分×0.3 + 基础分0.2`，上限 1.0；**Q ≥ 0.6 才保留**。

### 4.1 保留条件（全部满足）

1. 三条文本均非空，主诉 ≥5 字符、整体 ≥8 字符。
2. 中文占比 ≥ 50%（非乱码）。
3. 三段语义自洽：追问确含"追问症状"的疑问要素词（什么/哪里/多久/是否/有没有/伴随/既往等）。
4. 医生话不命中任何黑名单（诊断/用药/治疗动作）。
5. 无隐私敏感词、无脏正则匹配。

### 4.2 剔除条件（任一命中即剔除）

- 非医疗问诊类对话（无科室命中且医疗关键词 <2）。
- 医生话含诊断结论 / 处方用药 / 检查治疗医嘱。
- 对话中无有效"追问→补充"配对。
- 命中隐私、URL、乱码、空轮次、重复样本。

### 4.3 明文隐私替换总则（防泄露）

即使原始中有可辨信息，清洗时一律**不原样保留**人名、年龄精确值、联系方式、家庭住址；仅在确实必须时用占位符（如"患者 / 张三"）替代，或直接丢弃。演示与评测语料一律使用**模拟样例**。

---

## 5. 例外规则：急重症提示语

任务书要求识别急重症时提示急诊。此类文本**不作为"预问诊追问"样本保留**，但因语义特殊可单独成类，供评测"急重症识别"模块使用：

| 标签 | 示例主诉 | 处理 |
| --- | --- | --- |
| `emo_emergency` | "胸口剧痛，喘不上气" | 不进入普通追问三元组；单独标注供急重症拦截评测 |

急重症触发词示例：胸痛、胸闷、呼吸困难、大出血、晕厥、意识不清、呼吸困难等 → 应提示"立即急诊就医或拨打 120"。

## 6. 样例质量验收指标

| 指标 | 目标 | 说明 |
| --- | --- | --- |
| 语料总量 | ≥ 100 条（评测集） | 跑批评测最低要求 |
| 追问覆盖五要素 | 主要症状/部位/时程/伴随/既往 均有分布 | 训练追问策略 |
| 科室多样性 | ≥ 10 个科室 | 保证科室推荐覆盖面 |
| 隐私命中率 | 0 | 任何一条含明文隐私即判失败 |
| 诊断/用药命中率 | 0 | 任何一条含诊断或开药即判失败 |
| 三元组完整率 | 100% | 主诉/追问/补充三段均非空 |

---

## 7. 语料迭代与版本管理

- 语料按 `YYYYMMDD` 进行版本标记，附清洗报告（`clean_report.json`）记录保留/剔除统计。
- bad case（评测未达标样本）回流规则：标注原因 → 调整追问策略或补充正样本 → 重新清洗。
- 仓库目录建议：

```
corpus/
  raw/                # 原始 JSON（只读,留痕）
  scripts/            # clean_inquiry_corpus.py
  clean/              # inquiry_corpus_clean.csv
  samples/            # 示例样例(脱敏)
  reports/            # clean_report.json / evaluation_report.json
```
