# 评测脚本（核心代码 / 伪代码）

- 版本：V1.0.0　·　作用：批量跑测试集 → 自动统计 4 项指标 → 收集 bad case
- 输入：`testsets/cases.csv`（或 `.json`，字段见《19_评测集设计与指标》）
- 输出：`evaluation/reports/` 下的指标 JSON、报告 Markdown、bad_case 清单

## 1. 主流程（伪代码）

```
输入: cases(测试集), agent_client(被测对话引擎)
输出: metrics_summary, report_md, bad_cases

初始化:
  coverage_hits, coverage_denominator = 0, 0           # 追问覆盖率累计
  report_complete_pass, top3_pass, time_list = 0, 0, []
  bad_cases = []

FOR each case IN cases:
  1) 驱动对话 loop（最多 N 轮，如 20 轮防死循环）:
     初始: 把 case.chief_complaint 作为"用户"首条输入发给 agent
     REPEAT:
        user_turn = 读取 agent 的回复
        if agent 触发 emergency:  记录 emergency=True; reply_emergency; break   # 结束，验拦截
        if agent 返回 report_ready(槽位齐):  取报告 report; break
        if agent 在追问(缺槽):  由"模拟患者"按 expected_slots 提供下一要素回答, 继续
        if agent 越界拒答:  记录 rejected
        measure 单轮响应耗时 → push time_list
     END REPEAT

  2) 计算该条指标:
     # a) 追问覆盖率: 期望槽位中被模型采到的比例
     hit = |expected_slots ∩ agent.slots|
     coverage_hits  += hit
     coverage_denominator += len(expected_slots)

     # b) 报告字段完整率: 四必填字段是否非空
     full = all(nonempty(report[chief|present|allergy|past]))
     if full: report_complete_pass += 1

     # c) 科室Top3准确率: 期望*首要*科室是否落在推荐Top3
     if case.expected_top3[0] in agent.recommend_top3:  top3_pass += 1

     # d) 急重症拦截正确性: expected.emergency 与 agent.triggered_emergency 一致
     if case.emergency != agent.triggered_emergency:  record_as_bad("急重症误判")

  3) Bad-Case 收集（任一不达标即记）:
     if 追问覆盖率(该条) < 0.9:      bad_case(tag="coverage", detail=missing)
     if 报告不完整:                  bad_case(tag="report")
     if 科室Top3未命中:              bad_case(tag="top3", predict=..., expect=...)
     if 回合不应答/超时:             bad_case(tag="timeout")

汇总:
  avg_coverage      = coverage_hits / coverage_denominator      *100
  report_completeness = report_complete_pass / |cases|          *100
  top3_accuracy     = top3_pass / |cases|                       *100
  avg_response_time = mean(time_list)
  生成 report.md 与 bad_cases.csv
```

## 2. 关键函数骨架（Python）

```python
# evaluate.py —— 核心实现骨架
from dataclasses import dataclass, field
from pathlib import Path
import json, csv, time, statistics

@dataclass
class Case:
    case_id: str; category: str; chief_complaint: str
    expected_slots: dict; expected_top3: list[str]; emergency: bool

    @classmethod
    def load(cls, path: str) -> list["Case"]:
        # 支持 .csv / .json,解析字段 → Case
        ...

@dataclass
class Report:
    filled: dict                            # {chief,filled,...}
    recommend_top3: list[str]

@dataclass
class RunResult:
    slots: dict = {}
    report: Report | None = None
    triggered_emergency: bool = False
    rejected: bool = False
    round_times: list[float] = field(default_factory=list)

def run_one_case(agent, case: Case, max_rounds: int = 20, patient) -> RunResult:
    """驱动一个用例的多轮对话,返回采集结果。patient 按 expected_slots 应答缺槽追问。"""
    r = RunResult()
    msg = case.chief_complaint
    for _ in range(max_rounds):
        t0 = time.perf_counter()
        reply, state = agent.step(msg)          # 返回结构化 reply 与状态
        r.round_times.append(time.perf_counter() - t0)
        if state["action"] == "emergency":
            r.triggered_emergency = True; break
        if state["action"] == "report_ready":
            r.slots = state["slots"]; r.report = state["report"]; break
        if state["action"] == "rejected":
            r.rejected = True; break
        msg = patient.answer_question(reply)    # 模拟患者按 expected_slots 补答
    return r

def top3_accuracy(res, case) -> bool:
    return bool(r.report) and case.expected_top3 and \
           case.expected_top3[0] in r.report.recommend_top3

def coverage(res, case) -> tuple[int, int]:
    hit = sum(1 for k in case.expected_slots if res.slots.get(k))
    return hit, len(case.expected_slots)

def report_complete(res) -> bool:
    required = ["chief", "present", "allergy", "past"]   # 四必填字段
    return bool(r.report) and all(r.report.filled.get(f) for f in required)
```

```python
# —— 批量评测主入口 ——
def evaluate(agent, cases, out_dir: Path):
    all_times, cov_h, cov_d, rep_ok, top_ok = [], 0, 0, 0, 0
    bad = []
    for c in cases:
        r = run_one_case(agent, c)
        hit, den = coverage(r, c)
        cov_h += hit;      cov_d += den
        rep = report_complete(r)
        top = top3_accuracy(r, c)
        rep_ok += int(rep);   top_ok += int(top)
        all_times += r.round_times
        if not (hit/den >= 0.9):         bad.append((c.case_id, "coverage", c, r))
        if not rep:                      bad.append((c.case_id, "report", c, r))
        if not top:                      bad.append((c.case_id, "top3", c, r))
        if c.emergency != r.triggered_emergency:
            bad.append((c.case_id, "emergency_mis", c, r))
    metrics = {
        "coverage":        round(cov_h/cov_d*100, 2),
        "report_complete": round(rep_ok/len(cases)*100, 2),
        "top3_accuracy":   round(top_ok/len(cases)*100, 2),
        "avg_response_s":  round(statistics.mean(all_times), 3),
    }
    write_report(metrics, bad)   # 写 report.md + bad_cases.csv
```

## 3. 判定与 Bad-Case 规则

| 指标 | 阈值 | 单条不达标即记 bad case |
| --- | --- | --- |
| 追问覆盖率 | ≥ 90% | 该条 `覆盖 < 90%`，记录 `missing_slots` |
| 报告完整率 | ≥ 90% | 四必填字段任一为空 |
| Top3 准确率 | ≥ 80% | 首要期望科室未进 Top3（记录实际推荐 vs 期望） |
| 平均响应时间 | ≤ 5s | 单轮 > 5s 记录 round_times 详情 |
| 急重症一致性 | 100% | `expected.emergency` 与 `triggered_emergency` 不一致即判 |
