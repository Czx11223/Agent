## 2. 科室推荐逻辑规则

### 2.1 基础规则

1. **急重症优先（最高优先级）**：命中急诊关键词（胸痛、呼吸困难、大出血、剧烈腹痛、晕厥/意识不清、过敏性休克、开放性骨折、高热惊厥等）时，**急诊科无条件置顶第 1 位**，其余科室按置信度排列；同时触发急诊提示话术并中止追问。
2. **症状→科室匹配**：将已收集的每个症状分别去查映射表，得到候选科室集合及各科室的**命中次数（权重）**。
3. **科室白名单**：仅输出表内定义的常见科室，超出范围以"内科/全科"兜底。

### 2.2 多症状融合计算（Top3 推荐算法）

当患者存在**多个症状**时，采用**加权投票 + 优先级修正**机制融合：

```
sketch:
  对每个症状 s ∈ {collected_symptoms}:
      dept_list[s] = 映射表中该症状的推荐科室 (1,2,3 带权重 w1>w2>w3)
  统计:
      score[d] = Σ_s ( 权重系数(s) × 名次权重(dept 在该症状中的 rank) )
      // 权重系数: 主要症状 main_symptom 记 1.0, 伴随症状 记 0.6, 既往史仅作风险因子 0.3
      // 名次权重: rank1=1.0, rank2=0.6, rank3=0.3
  修正:
      if 任一急重症关键词命中: score[急诊] = +∞  (急诊置顶)
      if symptom 命中"女性/妇科"或"小儿/儿科": 对应科室加权上浮
  排序:
      Top3 = 按 score 降序取前三;
      并列时优先"既有科室"命中更靠前者; 仍并列按科室白名单固定顺序
```

**关键点说明：**

- **主症主导**：患者"主要症状"的权重高于伴随症状，避免伴随症状喧宾夺主。
- **交集强化**：多个症状都指向同一科室时，该科室得分累加，命中数越多的科室排名越靠前。
- **专科优先**：同时命中多科室时，优先输出专科性更强的科室（对应 rank1 名的权重加成）。
- **急重症一票否决**：急诊命中不与普通科室并列，直接占用第 1 位推荐。
- **兜底**：无任何匹配或信息不足时，输出"内科（全科）→ 急诊→外科"顺序并提示继续补充症状。
