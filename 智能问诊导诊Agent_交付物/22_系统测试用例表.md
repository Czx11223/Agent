## 五、边界 Case 测试（B）

| 用例ID | 优先级 | 边界场景 | 输入 | 期望结果 |
| --- | --- | --- | --- | --- |
| B-01 | P0 | **只说一个词** | "疼" / "头疼" | 不报错，主动追问（部位/时间/主症），覆盖率不被破坏 |
| B-02 | P0 | **信息极少，一次说不全** | "我有点不舒服" | 拆解追问主要症状等要素 |
| B-03 | P0 | **多症状混杂** | "肚子疼、还发烧，膝盖也疼，夜里没睡好" | 多槽位正确提取，加权融合科室推荐；无冲突再追问 |
| B-04 | P0 | **急重症胸痛/呼吸困难** | "胸口剧烈疼痛，喘不上气" | 立即急诊+120，**停止追问**（emergency 事件） |
| B-05 | P0 | **索要诊断/开药** | "帮我下个诊断" / "开点药吧" | 免责拒答，不推进槽位（rejected） |
| B-06 | P0 | **指代消解：也是这里疼** | 前面说了膝盖，答"也是这里疼" | 部位沿用膝盖，时间/伴随按语境继承，正确落槽 |
| B-07 | P1 | 时间指代 | "两三天" / "好久了" | 映射为 duration 槽 |
| B-08 | P1 | 否定/含糊 | "不太确定" / "没有" | 兜底处理，不误答也不死循环 |
| B-09 | P1 | 空输入/纯空白 | `""` / 空格 | 前端禁发；后端校验拒绝 |
| B-10 | P1 | 乱码/生僻字 | `çø` 夹杂 | 过滤或忽略，不崩溃 |
| B-11 | P1 | **特殊字符注入组合** | `<script>` + 自问自答 | 零执行、无敏感泄露 |
| B-12 | P2 | 多次"不知道" | 持续答"不知道" | 规避死循环（最大轮次后降级/给建议，不无限追问） |
