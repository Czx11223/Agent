# 追问要素清单

- 版本：V1.0.0　·　用途：预问诊多轮对话 Agent 的槽位定义与追问触发依据
- 追问链：**主要症状 → 部位 → 持续时间 → 伴随症状 → 既往史**，并扩展 过敏史、既往病史、急重症标识
- 约定：`必填` 要素缺失 ⇒ 必须触发追问；`条件必填` 视前一要素取值触发；`建议` 尽量采集，缺失不硬性追问

---

## 1. 要素定义表

| 要素 key | 中文名称 | 采集说明 | 是否必填 | 缺失是否触发追问 |
| --- | --- | --- | --- | --- |
| `main_symptom` | 主要症状 | 患者最核心的不适（如"咳嗽""胸痛"），对话首要采集项，作为追问起点 | **必填** | ✅ 主诉缺失/模糊时立即追问"您主要哪里不适？" |
| `body_part` | 部位 | 不适发生的身体部位（如"右侧胸肋""左膝"）；用于部位消解与诊断线索 | **条件必填** | ✅ 当主要症状与部位相关（疼痛/红肿/皮疹等）且部位未给明时触发 |
| `duration` | 持续时间 | 症状起始与持续时间（如"三天""近一个月"），区分急性/慢性，辅助科室推荐 | **必填** | ✅ 追问"这种情况持续多久了？" |
| `accompanying_symptom` | 伴随症状 | 与主症并发的其他症状（如咳嗽伴发热、胸闷伴气短），增强科室判别 | 建议 | ⚠️ 主要症状高危时（如胸痛/发热）缺失则触发追问 |
| `past_history` | 既往史 | 既往重大病史（高血压、糖尿病等），影响风险评估 | 建议 | ⚠️ 高风险科室场景（心血管/神经/消化）缺失则触发 |
| `allergy_history` | 过敏史 | 药物/食物过敏史（如青霉素过敏），是安全关键要素 | 建议 | ⚠️ 涉及用药史、或既往有过敏提示时触发 |
| `emergency_flag` | 急重症标识 | 非追问项：由规则/模型识别（胸痛、呼吸困难、大出血、剧烈腹痛、晕厥等），命中即提示急诊 | **系统判定** | ✅（自动）一旦命中急重症，**中止常规追问**，转入急诊提示，不依赖用户回答 |

> 说明：`emergency_flag` 不作为"追问获得"的要素，而是**主动识别**后的拦截标记；识别后优先于整个追问链执行。

## 2. 追问链顺序与终止条件

```
① main_symptom（必问）
     │ 已明确
     ▼
② body_part（条件必问）
     │
     ▼
③ duration（必问）
     │
     ▼
④ accompanying_symptom（高危时问）
     │
     ▼
⑤ past_history / allergy_history（建议问）
     │
     ▼
⑥ 完成度判断：五类关键要素是否齐备
   ├─ 齐备 → 生成预问诊报告 + 科室推荐
   └─ 缺失必填项 → 回溯补齐对应追问
   （任意时刻命中 emergency_flag → 转入急诊提示并终止问诊）
```

**终止条件**：所有"必填/条件必填"要素已填充且完成度 ≥ 阈值，或命中急重症拦截。
**槽位示意**（对应数据库 `conversation.slot_state`）：

```json
{
  "main_symptom": "咳嗽",
  "body_part": "",
  "duration": "三天",
  "accompanying_symptom": "发热、咳痰",
  "past_history": "高血压",
  "allergy_history": "无",
  "emergency_flag": false,
  "progress": {"main_symptom": true, "body_part": true, "duration": true,
               "accompanying_symptom": true, "past_history": true}
}
```

## 3. 关键追问话术模板（示例）

| 要素 | 追问模板（占位） |
| --- | --- |
| 主要症状 | "您好，请问您主要是哪里不舒服呢？" |
| 部位 | "这个疼痛（红疹/不适）具体在哪个位置？比如左胸还是右胸？" |
| 持续时间 | "这种情况大概持续多久了？是从什么时候开始的？" |
| 伴随症状 | "除了这个问题，还有没有伴随的比如发热、气短、头晕等情况？" |
| 既往史 | "您之前有没有高血压、糖尿病这类慢性病史？" |
| 过敏史 | "您对什么药物或食物过敏吗？" |
