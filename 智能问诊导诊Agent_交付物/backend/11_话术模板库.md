# 话术模板库（追问 / 情绪安抚 / 急重症 / 免责拒答）

版本：V1.0.0　·　设计目标：每个追问要素提供**多套话术轮换**，避免对话中重复文案；安抚、急重症、拒答话术分类管理。

---

## 1. 追问模板库（随槽位缺失触发轮换）

> `TemplateBank.ask(slot_key)` 按下标 `round%n` 轮换引用可用的套系，同一会话尽量不连续命中同一句。

### 1.1 主要症状 `main_symptom`

| 序号 | 话术 |
| --- | --- |
| A1 | 您好，请问您主要是哪里不舒服呢？ |
| A2 | 麻烦您说说您现在最明显的不适是什么？ |
| A3 | 您今天主要是因为什么问题来咨询的呢？ |

### 1.2 部位 `body_part`

| 序号 | 话术 |
| --- | --- |
| B1 | 这个不适具体在哪个位置？比如左侧还是右侧？ |
| B2 | 能告诉我是身体的哪个部位吗？胸口、腹部还是其他位置？ |
| B3 | 麻烦再具体一点，不适集中在哪个部位呢？ |

### 1.3 持续时间 `duration`

| 序号 | 话术 |
| --- | --- |
| C1 | 这种情况大概持续多久了？从什么时候开始的？ |
| C2 | 这个症状出现多长时间了呢？ |
| C3 | 最近这样的不适，大概是多长时间了？ |

### 1.4 伴随症状 `accompanying_symptom`

| 序号 | 话术 |
| --- | --- |
| D1 | 除了这个问题，还有没有伴随的发热、气短、头晕等情况？ |
| D2 | 有没有其他一起来的症状呢？ |
| D3 | 同时还有没有不舒服的其他表现吗？ |

### 1.5 既往史 `past_history`

| 序号 | 话术 |
| --- | --- |
| E1 | 您以前有没有高血压、糖尿病这类慢性病？ |
| E2 | 方便告诉我您既往的健康情况吗？ |
| E3 | 您有没有需要长期服药的慢性病史？ |

### 1.6 过敏史 `allergy_history`

| 序号 | 话术 |
| --- | --- |
| F1 | 您对什么药物或食物过敏吗？比如青霉素？ |
| F2 | 有过药物或食物过敏的情况吗？ |
| F3 | 请问您的过敏史，平时吃什么药或食物有没有过敏的？ |

## 2. 情绪安抚话术库

| 情绪标签 | 触发词示例 | 安抚话术（情绪后置，随后继续追问） |
| --- | --- | --- |
| `anxious` 焦虑 | 焦虑、紧张、担心 | 别担心，我们先一步一步把情况理清楚，这样医生接诊会更从容。 |
| `fear` 恐惧 | 害怕、吓死、恐惧 | 我理解您的担心，如实地告诉我最真实的情况就好，我们一起把它说清楚。 |
| `pain` 疼痛 | 很痛、疼得厉害、疼死 | 听上去确实很难受，辛苦了。请尽量描述一下疼痛的感觉，我来帮您记录。 |
| `distress` 难受 | 难受、不舒服、很累 | 不舒服一定很难熬，没关系，简单说两句也都可以。 |

> 使用：`安抚话术 + 追问话术` 拼接触发（如 `comfort + followup`），保证在追问前先给出同理心。

## 3. 急重症触发回复模板（命中即停止问诊）

```text
【急重症提示】
您描述的这些表现（如胸痛、呼吸困难、大出血、剧烈腹痛、晕厥等）可能属于需要紧急处理的急重症。
请您立即前往医院急诊科，或尽快拨打 1 2 0 急救电话，切勿耽搁。
—— 预问诊助手仅用于挂号参考，不能替代紧急医疗处置。
```

> 变体（视命中词微调，不改"立即急诊/拨打120"核心指令）：
> - 胸痛/胸闷：…"请您立即到急诊科，评估是否为心脏相关问题"。⚠️ 措辞避免"诊断"，仅作急诊引导。
> - 大出血/剧烈腹痛：…"请立刻就近急诊，注意保持体位舒适，避免自行盲目处理"。

## 4. 免责拒答模板（越界问题：索要诊断 / 开药）

```text
【免责声明】
非常抱歉，我是预问诊助手，职能是为您整理症状信息并推荐就诊科室，
**不能提供医学诊断，也不能开具药物或治疗方案**。
您的问题已超出导诊范围，建议您尽快到医院相关科室请执业医师面诊，以医生的判断为准。
如有不适加重，请及时就诊或拨打 1 2 0。
```

> 变体（更简短）：
> "抱歉，诊断与用药需要由执业医师面诊后判断，我无法给您这方面建议。建议尽快线下就医。以上内容仅供挂号参考。"

## 5. TemplateBank（代码集成）

```python
class TemplateBank:
    def __init__(self):
        self._ask = {
            "main_symptom":        ["A1", "A2", "A3"],
            "body_part":           ["B1", "B2", "B3"],
            "duration":            ["C1", "C2", "C3"],
            "accompanying_symptom":["D1", "D2", "D3"],
            "past_history":        ["E1", "E2", "E3"],
            "allergy_history":     ["F1", "F2", "F3"],
        }
        self._comfort = {
            "anxious": "别担心，我们先一步一步把情况理清楚。",
            "fear":    "我理解您的担心，我们一起把它说清楚。",
            "pain":    "听上去确实很难受，辛苦了。",
            "distress":"不舒服一定很难熬，没关系，简单说两句也都可以。",
        }
        self._round = 0   # 会话级轮换计数

    def ask(self, slot: str) -> str:
        pool = self._ask.get(slot, [])
        if not pool:
            return "您能再补充一些细节吗？"
        return pool[self._round % len(pool)]   # 轮换防重复

    def comfort(self, emotion: str | None) -> str:
        return self._comfort.get(emotion, "")

    @staticmethod
    def emergency() -> str:
        return ("【急重症提示】您描述的这些表现（如胸痛、呼吸困难、大出血、剧烈腹痛、晕厥等）"
                "可能属于需要紧急处理的急重症。请您立即前往医院急诊科，或尽快拨打120急救电话，切勿耽搁。"
                "—— 预问诊助手仅用于挂号参考，不能替代紧急医疗处置。")

    @staticmethod
    def disclaimer() -> str:
        return ("【免责声明】非常抱歉，我是预问诊助手，职能是为您整理症状信息并推荐就诊科室，"
                "不能提供医学诊断，也不能开具药物或治疗方案。建议尽快到院请执业医师面诊，以医生判断为准；如有不适加重请及时就诊或拨打120。")

    @staticmethod
    def report_prefix(report_md: str, depts: list) -> str:
        return (report_md + "\n\n> 以上内容均来源于患者口述，仅供挂号和医生接诊参考，"
                f"不构成医学诊断或治疗建议。推荐科室：{'、'.join(depts)}。")
```

## 6. 话术使用约束

1. 同一会话内追问话术逐步轮换，避免"逐字重复"造成机械感。
2. 安抚话术始终**先于**追问话术输出。
3. 急重症话术**优先级最高**，命中后不再追加追问；免责拒答后本轮不推进槽位。
4. 所有模板仅作信息收集与挂号参考引导，**不含诊断、不含用药、不含治疗承诺**。
