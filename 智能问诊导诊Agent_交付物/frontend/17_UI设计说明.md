# 前端 UI 简单设计说明

- 版本：V1.0.0　·　设计目标：医疗问诊场景，**简洁、信任、清晰**；PC + 移动端响应式。

---

## 1. 布局结构

```
┌──────────────────────────────────────────────────────────────┐
│  Header（可选：Logo + 用户信息/退出）                          │
├───────────────┬──────────────────────────────────────────────┤
│ 会话列表(侧栏) │   聊天对话窗口 / 预问诊报告                    │
│ · 新建问诊按钮 │   · 消息气泡（左AI / 右用户）                  │
│ · 历史会话      │   · 流式打字光标 ▍                            │
│ Navigation     │   · 底部输入框 + 发送                          │
├───────────────┴──────────────────────────────────────────────┤
│  Footer（常驻免责声明，居中、浅色小字）                          │
└──────────────────────────────────────────────────────────────┘
```

- **PC（≥768px）**：左侧固定会话列表（`w-72/80`，带边框），右侧聊天/报告区。布局使用 `flex h-screen` 全屏撑满。
- **移动端（<768px）**：隐藏侧栏，改为 `Drawer`（居左，点击会话条目或右上角菜单唤起）；聊天区占满宽度；输入框贴底。

## 2. 色彩与风格

| 用途 | 值 | 说明 |
| --- | --- | --- |
| 主色（用户消息/主按钮） | Ant Design `blue`（#1677ff） | 信任感，医疗蓝 |
| 背景 | `slate-50` | 浅灰，柔和 |
| AI 消息气泡 | `slate-100`（浅灰） | 与用户区分 |
| 报告/标签 | `sky/blue` Tag + 白色卡片 | 强化结构化 |
| 免责声明 | 灰色 `secondary` 小字 | 视觉弱化但常驻 |

语气：克制、专业、不高饱和。圆角 `rounded-2xl` 气泡、`rounded` 卡片，整体轻盈。

## 3. 组件划分与职责（对应组件文档）

| 组件 | 职责 | 响应式要点 |
| --- | --- | --- |
| `ConversationList` | 会话列表（新建/选择/状态） | PC 常显；移动端嵌 Drawer |

## 4. 交互说明

- **SSE 流式**：`POST /chat/stream` 用 Fetch 逐 Token 解析 `data:` 行，实时追加到最后一条 AI 气泡；`emitting` 时显示光标 `▍` 并禁用发送按钮。
- **会话切换**：点会话条目 → 拉取 `GET /conversations/{cid}/messages` → 回填历史并重置报告视图。
- **问诊完成**：收到 `done.next === "report_ready"` → 拉取报告 → 展示 `ReportPanel`（桌面内联 / 移动端可切页），并弹窗/页内呈现 Top3。
- **复制/导出**：`navigator.clipboard` 复制；`Blob` 生成 `.md` 文件下载。
- **报告与聊天的切换**：PC 上报告就绪后替换聊天区显示报告；提供"返回对话"入口。
- **常驻免责**：页面底部 Footer 始终显示"仅供挂号与接诊参考，不构成医学诊断"，与急重症/拒答时的行内提示配合。

## 5. 响应式断点

| 断点 | 聊天 | 会话列表 | 报告 |
| --- | --- | --- | --- |
| `< 768px`（手机） | 全宽 | Drawer | 独立页/弹层 |
| `≥ 768px`（平板/桌面） | 右侧区域 | 固定侧栏 | 右侧内联 |

- 使用 Tailwind 前缀 `md:` 在桌面显示侧栏、移动隐藏；`flex-wrap` 让科室标签自适配。
- `viewport` 已按标准配置，保证移动端渲染不乱。

---

## 6. 无障碍与浏览器兼容

- 主流浏览器（Chrome、Edge、Firefox、Safari）**最新两个大版本**均支持：`fetch` 流式读取、`navigator.clipboard`、`Blob` 下载。
- 无障碍：AntD 组件自带 ARIA；气泡颜色对比度足够；发送按钮可回车触发。
- 兜底：`clipboard` 不可用时静默忽略（try/catch）；SSE 断流时展示错误占位。
